# 外科医 夜勤シフトスマートマネージャー 🏥

4名の外科医向けに特化した、ワンクリックで簡単・公平に夜勤シフトを決定・管理できるWebアプリケーションです。

## 🌟 主な機能

- **ワンクリック勤務選択**: カレンダー内の医師バッジをクリックするだけで、勤務のON/OFFを切り替え。
- **1クリック自動シフト生成**:
  - 連続夜勤の自動回避
  - 4人での勤務回数・週末勤務数の公平な自動配分
  - 希望休（不可日）の回避計算
- **不可日（希望休・学会等）のワンクリック登録**
- **リアルタイム集計メーター**: 月間の勤務回数・平日/休日内訳を自動可視化。
- **Googleカレンダー連携 & カレンダーエクスポート**:
  - **.icsファイル一括ダウンロード**: Googleカレンダーやスマホカレンダーにワンタップで勤務予定を一括インポート。
  - **Googleカレンダー直接追加**: 勤務日ごとのダイレクト追加リンクを生成。
  - **カレンダー用テキストコピー**: 勤務予定を読みやすい形式でコピー。
- **共有機能**:
  - **共有リンク発行**: 現在のシフト状態を含んだURLを発行（LINEやメールで送るだけで同じシフトを開けます）。
  - **テキスト共有**: LINE等に直接貼り付けられるテキスト出力。
  - **CSVダウンロード & 印刷対応**

## 🚀 使い方

`index.html` をブラウザで直接開くか、GitHub Pages などの無料ホスティングで共有してお使いいただけます。
